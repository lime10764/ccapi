发信通道

开发模式下不会真正发邮件：验证码会显示在「概览」页，并打印到 Worker 日志（wrangler tail）。适合先联调登录流程。
推荐 QQ/163 邮箱：Worker 通过 cloudflare:sockets 直连 SMTP，不需要额外服务器。 去邮箱「设置 → 账户」开启 SMTP/IMAP 服务，生成授权码（不是登录密码）。常用： QQ smtp.qq.com:465、163 smtp.163.com:465、Outlook smtp.office365.com:587。
注册 resend.com（免费额度每月 3000 封），在 API Keys 页创建密钥；发件域名需在 Resend 验证，测试期可直接用官方 onboarding 发件地址。
高级：自己部署 Node 邮件服务（nodemailer）。SMTP 账号在上方「SMTP 直连」里填写即可，邮件服务每分钟自动拉取；这里只填服务地址。
